# Aurora

A crisp, modern theme for technology, lifestyle and design-led brands. Cool aurora accents, generous whitespace and clean product cards. It is a data-only theme: no code, only `theme.json`, images and demo content.

## What it shows

- **Palette presets.** Aurora ships three ready-made palettes under `customizer.presets` — `aurora` (teal), `slate` (cool grey) and `ember` (warm). Applying one from **Admin → Appearance → Customize** sets colors, typography, radius and density at once; every field stays editable afterwards.
- **Dark mode.** `dark_colors` are declared, so the storefront follows the shopper's device theme.
- **Home sections.** A hero, a product grid, a category grid, an image-with-text panel and a promo banner.

## Design

| Setting             | Default          |
| ------------------- | ---------------- |
| Primary             | `#0d9488` (teal) |
| Body / heading font | `sans`           |
| Radius              | `0.75rem`        |
| Density             | `comfortable`    |
| Header              | `classic`        |
| Footer              | `columns`        |
| Product cards       | `standard`       |
| Grid                | 4 per row        |
| Product page        | `split`          |

## Install

Drop the `aurora/` folder into `themes/ecomodular/`, or upload its ZIP under **Admin → Appearance → Upload theme**. The theme is discovered on the next sync; preview it, then activate it.

## Demo content

`demo.json` adds three categories and six products. Slugs and SKUs are prefixed `aurora-` so they never collide with real catalog data.
